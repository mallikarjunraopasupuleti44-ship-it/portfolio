# P. Mallikarjuna Rao — Interactive AI Portfolio

A modern, immersive personal portfolio website designed and built for **P. Mallikarjuna Rao** (AI & Data Science Student / Software & AI Builder).

## ✨ Features

- **Cinematic Cosmic Intro**: Deep-space starry background with animated star canvas and dynamic celestial effects.
- **Interactive AI Companion Robot**:
  - Smooth 3D-styled SVG/Canvas-rendered flying companion with dynamic thruster flame animations.
  - Interactive speech interface with Web Speech API voice synthesis and real-time typewriter dialogue.
  - Scroll-linked positioning and responsive docked states.
- **Ultra-Smooth Scroll Experience**: Powered by **Lenis** smooth scroll and **GSAP ScrollTrigger** timeline choreography.
- **Cyber-Glassmorphism UI**: High-contrast, glowing neon accents, frosted glass panels with backdrop blur, and custom typography using Syne and Plus Jakarta Sans.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile screen sizes.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/) & [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) & Vanilla CSS with modern glassmorphism
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock) & [ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) with your browser to view the portfolio.

## 📦 Build & Deploy

To create an optimized production build:

```bash
npm run build
npm run start
```
